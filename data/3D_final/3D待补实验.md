# 3D legacy 最小补点计划

> 执行终态（2026-08-12）：yuany/nd-3 自适应 pilot 已完成并停止。两波均使用 69 workers（上限 70）：`.230` 与 `.240` 各运行 `q={.012,.022,.030}`、`L={3,7}`、48 disorders，共 12 cells。三个 q 到 `.240` 均未严格翻号，因此 `.225/.235` 与 384-disorder production 未运行。两份 `p=.220` raw 已从共享盘只读恢复并在 [`legacy_delta_only_nd3_pilot_20260811/validation.json`](legacy_delta_only_nd3_pilot_20260811/validation.json) 中 PASS。

## 1. 范围与权限

- 本计划只补 `legacy_delta_only`，目标是解析现有 `p=0.22` 与 q=0 finite-size internal anchor 之间尚未测量的 data-error bracket。
- 48-disorder pilot 只用于决定下一批候选点，不能产生正式 threshold、论文图或渐近结论。
- reduced-MLD 不得继承这里的点、gate 或论文权限。若目标改为 reduced-MLD，必须先独立实现并验证 `true_posterior`，再重新设计实验。
- 本文已构成上述 nd-3 adaptive pilot 的运行规格；384-disorder production 仍未授权。

## 2. 前置条件：先恢复 p=0.22 的 per-disorder 证据

exp41/005 的 `p=0.22` 两份 per-disorder NPZ 已从共享盘恢复到新的活动目录；源 SHA256、完整网格、seeds、flags、冻结 headline 与 `D_q(0.220)` 均已严格校验。冻结 exp41 目录保持不变。

恢复后至少校验：

1. `delta_f_per_disorder`、`p/q/L` 网格、disorder 数和 seed/disorder 索引齐全；
2. 每个 planned cell 无 invalid 或 missing，且 L=3/4/5/7 各为 384 disorders；
3. 从 `delta_f_per_disorder` 重算的 exp41/005 headline 与冻结 summary 一致；
4. 文件来源、SHA256 和校验结果写入新的实验目录，不改写冻结 exp41 目录。

若未来发现恢复证据失效，才把 `p=0.220` 加入重跑：先做 `q={0.012,0.022,0.030}`、`L={3,7}`、每 cell 48 disorders 的 baseline pilot；正式发表前补齐 `L={3,4,5,7}`、每 cell 总计 384 disorders。当前校验已 PASS，此 contingency 不执行。

## 3. 决策统计量

对每个固定 q 定义

`D_q(p) = mean[w0(L=3)] - mean[w0(L=7)]`。

- 只使用该 `(p,q,L)` planned cell 的完整 disorder 集；invalid 或 missing 一律 fail-closed，不以 valid-only 子集补 mean。
- `D_q(p)=0`、点估计方向不确定，或其 95% bootstrap CI 包含 0，均记为 `unresolved`，不得当作变号。
- 严格 bracket 要求同一 q 的两个 p 端点 `D_q` 严格异号，且两个端点的 95% CI 都不包含 0。
- 饱和区恰好零差值、低-pass 深尾和已知非单调伪影不参与变号判断。

## 4. 自适应 pilot 与执行结果

候选 p 池是 `.225/.230/.235/.240`，不是默认全跑的笛卡尔积。每个被选中的 `(p,q)` 只先运行 `L={3,7}`、每 cell 48 disorders。

1. 首批只测 `p=0.230`：`q={0.012,0.022,0.030}`、`L={3,7}`，共 6 cells。
2. 对在 `.220` 与 `.230` 已形成严格异号的 q，补该 q 的 `p=.225`，把 bracket 细化到宽 0.005。
3. 对 `.230` 尚未相对 `.220` 严格翻号的 q，跳到该 q 的 `p=.240`；若只在 `.240` 才形成严格翻号，再补 `p=.235`。
4. 若 `.240` 仍未严格翻号，或任一端点方向为 `unresolved`，该 q 立即停止，不升到 384，并重新设计 p/q 扫描范围。
5. 在已校验 `.220` baseline 的前提下，自适应部分最坏为 18 个 pilot cells：`.230` 6 个、`.240` 6 个、`.235` 6 个；`.225` 只替代对应已在 `.230` 翻号的分支，不默认与后三批同时全跑。

运行实现固定在 [`legacy_delta_only_nd3_pilot_20260811/`](legacy_delta_only_nd3_pilot_20260811/)；每个 task 原子 checkpoint，每波只使用一个进程池，不允许多个 pool 超订。

实际执行只触发步骤 1 和步骤 3：

| q | `D_q(.230)`（95% CI） | `D_q(.240)`（95% CI） | 终态 |
|---:|---:|---:|---|
| .012 | -0.0005762 [-0.0013232, -0.0002020] | -0.0003595 [-0.0003777, -0.0003492] | STOP：`.240` 前未翻号 |
| .022 | -0.0033859 [-0.0095853, -0.0002529] | -0.0081285 [-0.0225408, -0.0005974] | STOP：`.240` 前未翻号 |

所有端点的 95% CI 均不含零，L3/L7 pass fraction 均在 `0.979–1.000`。机器可读终态见 [`pilot_decision.json`](legacy_delta_only_nd3_pilot_20260811/pilot_decision.json)；没有严格 bracket，故不满足下一节的 production 前提。

两波的单线程 task 墙钟求和为 328.54 小时（`.230`: 164.08；`.240`: 164.46）；这不是硬件 CPU counter。自适应停止省去了 `.235` 的 6 cells 及全部 production，并且没有用多进程池超订来缩短墙钟。

## 5. 正式提升与 gate

只提升已经形成严格 bracket 的 q 窗口。对 bracket 两端的每个保留 `(p,q)`：

- 将 L=3、7 从 48 top-up 到每 cell 总计 384 disorders；
- 新增 L=4、5，每 cell 总计 384 disorders；
- 不补 L=6；不把其他未形成 bracket 的候选点顺带升档。

正式结果必须同时满足：

1. crossing 位于已扫描 p 区间内部，不贴扫描边界；
2. crossing 核心 pass fraction `>=0.9`；
3. disorder bootstrap crossing fraction `>=0.95`；
4. 多个有杠杆的 L 对给出相容的方向与 crossing；
5. 任一 planned cell invalid 或 missing 时 fail-closed，正式 mean、crossing 和 FSS 均为空；
6. 排除饱和零差值、低-pass 深尾、p=0.05 L7 非单调尾等已知伪影；
7. 只报告 `w0` 有限尺寸 crossing；`q_top/q_W` 仍是 companion only，不生成第二套 threshold headline。

即使全部 gate 通过，也只形成 `legacy_delta_only` 的有限尺寸 bracket。任何渐近 FSS、sharp-knee 形状或 reduced-MLD 结论都需要另立证据链。
