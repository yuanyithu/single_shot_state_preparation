# exp36/018 final q-grid sector-gate summary

更新时间：2026-06-02（本机 Asia/Shanghai；远端 final NPZ 均已完成）

## 范围

018 已完成 `L=3,4,5,6`、`p=0.05`、`q=0.08..0.23` 的 64-disorder 生产扫描。
每个 `(q,L)` 都有 `64/64` disorder 和 final NPZ。

本汇总使用 `src/summarize_exp36_sector_gate.py` 对每个 q 的 final chunks 运行
10000-bootstrap sector-histogram gate。生产链覆盖 `4/8` 个 zero-syndrome
sector 初态：

`000,100,010,110`

这个 gate 的物理含义是：固定 disorder 后，比较不同初态链在 cold endpoint
采到的 Wilson-loop sector histogram。如果 MCMC 已进入该 disorder 的热态，
这些 histogram 应只差有限采样噪声。

## 总体结论

- 64 个 `(q,L)` 生产点中，61 个生产 gate 直接通过。
- 3 个生产边界 fail 都出现在 `L=3`：
  `q=0.13,d52`、`q=0.18,d10`、`q=0.23,d15`。
- 这 3 个 fail 均已用 targeted `8/8` 初态、`m=8192` 长链 reference 清除。
- 当前没有看到“不同初态长期驻留在不同 Wilson-loop sector，但 `q_top` 恰好接近”的稳定信号。
- 018 的最终 `q_top` 数值可作为当前算法版本的 disorder-averaged 采样结果；但生产链本身仍只覆盖 `4/8` 初态，边界点的强证据来自 019/020 reference。

## 物理解读

从 sector histogram 角度看，当前算法版本在目标窗口内没有暴露稳定的不热化信号：
同一个 disorder 下，不同 logical-sector 初态最终采到的 cold Wilson-loop sector
驻留分布一致到有限采样噪声范围内。

从 `q_top` 曲线看，`L=4,5,6` 在 `q<=0.23` 仍接近 1，`L=3` 随 q 增大下降且
disorder 方差较大。gap 图没有给出 crossing window：`L3-L4` 与 `L4-L5`
在整个窗口内为负，即更大 L 的 `q_top` 更高；`L5-L6` 是很小的正 gap，
但两条曲线都贴近 1。这说明固定 `p=0.05` 的该窗口内，大尺寸仍处在高
`q_top` 区域；本轮不支持用这些点宣称一个干净的 q-threshold crossing。
