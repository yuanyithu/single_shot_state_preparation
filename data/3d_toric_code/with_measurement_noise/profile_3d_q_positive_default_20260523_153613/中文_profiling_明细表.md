## 读表说明

- 一个“实验组”指同一个 `L,p,q,config`；本次 full run 一共有 34 个实验组。
- `q_top跨链极差` 不是某个更新环节的量，而是整个实验组的收敛诊断：每个 disorder 内算各 chain 的 `q_top`，取 `max-min`，再对 disorder 求平均。

- `PT交换` 的接受概率只对启用 PT 的实验组有意义。
