# exp35 2026-05-27 审计记录

结论：本目录的 pooled 数据文件和绘图输入没有明显拿错，但结果不能作为 threshold 物理结论。主要问题是 logical-sector mixing 严重不足，而 convergence gate 漏判了这类失败。

## 数据完整性

- `manifest_summary.json` 有 `128` 行，即 `2` 个 host x `4` 个 L x `16` 个 q。
- `num_missing_final_npz=0`。
- 每个 pooled `(L,q)` 都是 `2048` disorder。
- manifest 中 `cluster_update_enabled=False`、`adaptive_pt_rounds=3`、`num_start_chains=8`、`q0_num_start_chains=8`、`common_random_disorder_across_p=True`，与 launch 配置一致。
- pooled summary 的 `source_paths_by_lattice_and_q` 指向本目录下对应 `pooled/L*/q_*/*.npz`，没有发现把 pilot 或 exp34 文件混入。

## 图上现象

- L=4/5 不是没有误差条，而是 95% CI 极小。L=5 的 CI 约 `1.3e-4` 到 `3.2e-4`，在 marker 尺寸下几乎不可见。
- `L=6` 低于 `L=5` 是 pooled 数据中的真实数值，不是画图读反。`q_top(L5)-q_top(L6)` 从 `q=0.08` 的 `+0.000155` 增加到 `q=0.19` 附近的 `+0.002203`，之后仍约 `+0.0020`。
- gap 图定义是 `q_top(L_small)-q_top(L_large)`；负值表示大尺寸更好。

## 主要失败信号

`diagnostics_summary.json` 中 q>0 的 `64` 个点只有 `31` 个通过 gate。更严重的是，一些被标记为通过的点仍然显示 logical-sector transport 失败。

代表点：

- `L=6,q=0.08` 被标记为 `passed=True`，但平均 `6.55/8` 条链在生产测量段从未改变 logical sector。
- 同一点 cold winding acceptance mean 只有约 `2.99e-6`，mean PT min swap acceptance 只有约 `5.89e-5`。
- convergence gate 目前只在 cold winding acceptance 极低且 mean PT min swap acceptance `<=0` 时触发 `pt_transport_insufficient`，因此漏掉了“swap 很小但非零”的失败点。
- `L=5,q=0.08` 平均 `7.27/8` 条链从未改变 logical sector；`L=6,q=0.23` 虽改善到约 `0.18/8`，但曲线仍受到低温 logical-sector mixing 限制影响。

对 start sector 的 sanity check 显示，3D 的 8 个 start sector 本身能正确区分并抵消 logical observables；零 syndrome 下 `q_top_if_stuck=0`。因此异常不是 start label 生成器本身错误，而是正式 PT/burn-in/生产过程中链被驱到少数 sector，或生产诊断没有覆盖 burn-in 中已经发生的 sector 吸收。

## PT 参数问题

`sync_enlarge` 模式下 `pt_p_hot=0.44` 不等于实际热端 data probability。实际 ladder 由 `q_hot/q_cold` 的 odds 放大比例决定：

- `q=0.08` 时热端 `p_hot_actual≈0.3223`、`q_hot=0.44`。
- `q=0.23` 时热端 `p_hot_actual≈0.1216`、`q_hot=0.44`。

所以高 q 端实际 data 热端并不高，可能不足以帮助 L=5/6 logical-sector mixing。`pt_p_hot=0.44` 在该模式下主要是旧接口参数，不应在报告中解读为实际热端 p。

## 结论

`fixed_p050_q080_230_exp35_joint_pq_adaptive_pt_nd12_pooled_sem95.png` 不能解释为 `p=0.05` 下 q-threshold 在 `0.23` 右侧，也不能据此判断“大 q 区间内一直 L 越大 q_top 越大”。当前结果应标记为采样/诊断失败产物。

后续重新运行前应至少修正：

- convergence gate：把 `num_chains_that_never_flipped_sector`、cold winding acceptance、PT min swap 的小正值阈值纳入失败条件。
- diagnostics：记录 burn-in 前后 start sector 是否被吸收到同一 sector。
- PT 配置：重新设计 high-q 端的实际 `p/q` ladder，或增加更强的 sector-changing move，而不是只依赖当前 `sync_enlarge`。
