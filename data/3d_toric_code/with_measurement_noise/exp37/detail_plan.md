# detail_plan.md — exp37 正确采样 q_top 的分步工作流（执行 agent 唯一权威规范）

> 本文件是任务的唯一权威规范。配套的 `prompt.md` 只负责「定位当前阶段 → 推进一步 → 过闸门 → 更新进度」，所有判据细节以本文件为准。
> 进度记录在同目录 `STATUS.md`。每次开工先读 `STATUS.md` 定位当前阶段，再读本文件对应阶段执行。

## 0. 目标（一句话）

对 3D toric code 纠 X 错误的统计力学模型，正确估计每个 disorder 下 8 个逻辑扇区的相对自由能 `ΔF_g`，由此得到 `w_g[8]` 和 `q_top=(8·Σ_g w_g² − 1)/7`，最终给出可信、可证伪、可复现的曲线 `q̄_top(L, p, q)`。

物理图像与 L·T·S 分解、energy/observable 定义见仓库根 `CLAUDE.md`「物理图像与 L·T·S 分解」一节——执行前务必读一遍，本文件不重复。

## 1. 为什么要重做（前车之鉴，必须理解）

`032_final_corrected_qgrid` 用 AIS `flip_reweight`（**单步自由能微扰**）当生产估计量：要测次主导扇区权重，它在主导扇区的平衡态上**一次性插入一条固定 winding loop**，权重 `~exp(−Kp·|loop|)`，随 L 指数下溢。结果 L≥4 的次主导扇区权重 `w_sub` 掉到 `1e-12…1e-20`（8192 个粒子根本测不出这么小的概率，是下溢噪声），`q_top` 被顶到 1，却因为「全局 AIS ESS 还行」被判 PASS。

两个根因，本计划针对性修复：
1. **估计量错**：用单步指数平均跨越随 L 线性增长的逻辑自由能势垒，偏差单向（永远把 q_top 往 1 推）且随 L 指数放大 → 改用**增量式 sector-resolved TI** 主线。
2. **闸门失明**：全局 ESS 由主导扇区主导，对「次主导扇区是否被分辨」几乎没信息 → 改用**外部可证伪闸门**（精确解 / 第二独立方法 / 解析锚点）。

---

## 2. 全局铁律（每个阶段都适用，违反任意一条即该阶段判 FAIL）

1. **闸门 = 与外部参照对比的数字**。合法参照只有三类：① 小尺寸精确枚举；② 第二种独立估计量；③ 解析锚点（如 `Kp=0` 时 8 扇区严格等权、`q_top=0`）。**「内部自洽 / 多初态一致 / 曲线平滑 / 全部 PASS / 看着收敛」一律不算成功。**
2. **主估计量固定为 sector-resolved TI**（固定 `K_q`，沿 `K_p` 从 0 增量积分 `⟨|x|⟩_g` 得 `ΔF_g`）。**禁止**把单步 FEP / `flip_reweight` 当生产估计量。需要第二方法时，只能用**沿路径退火且双向（如 BAR / 双向 AIS）**的形式，且仅作交叉验证。
3. **红线（最重要）**：若某点除主导扇区外，所有 `w_g` 都低于统计分辨率（bootstrap 误差棒覆盖不住、或低于方法统计地板），该点必须标 `UNRESOLVED/FAIL`，输出「`q_top` 下界 + 未分辨」，**绝不允许报成 `q_top≈1`**。「`q_top≈1` 且 `w_sub` 未分辨」永远是失败，不是成功。
4. **benchmark 必须能失败**：金标准里必须包含若干真值 `q_top` 明显远离 1（落在约 `[0.2, 0.8]`）的点；否则任何偏估计量都会「看着对」，照不出问题。为此 benchmark 的 `(p, q)` 可以**自由选取**（不必等于生产值 `p=0.05`），只要 L=2 能精确求解、且真值落在中段。
5. **一次只推进一个阶段**。上一阶段未 PASS、未在 `STATUS.md` 贴出对比数字，不得进入下一阶段。
6. **可信性优先于速度**。宁可某点判 FAIL/UNRESOLVED，也不要为凑 PASS 放宽判据。判据阈值可微调，但必须在交付物里显式记录用了什么阈值。
7. 数据产物只写到本项目 `data/` 内；遵守 `CLAUDE.md` 的 conda 环境与服务器规则（本地 `12`，远端 `11` + `screen`，不临时装包）；每完成一个阶段，增量更新 `笔记/实验报告.md`（中文、简洁）。

## 4. 阶段定义

> 每个阶段四要素：**目的 / 做什么（高层，不规定实现细节）/ 成功闸门（外部、数字）/ 交付物**。阈值为推荐默认值，可微调但需记录。

### Stage A — 模型对齐与解析锚点（不采样）

- **目的**：确保执行 agent 与规范用的是同一个模型，把能在「不采样」前提下验证的东西先钉死。
- **做什么**：用生产代码路径计算 energy、sector 标签 `g=P_L x`、`q_top` 公式；在 L=2（n=24 个 qubit，可全枚举 2²⁴）上与暴力逐构型对照。
- **成功闸门**（全部 bit 级 / 数值精确）：
  - A1：随机 ≥1000 个 `x`，生产代码的 `E(x)=Kp|x|+Kq|H_Z x ⊕ m_err|` 与暴力值逐位一致。
  - A2：L=2 精确枚举下，按 sector 标签聚合的 8 个 `Z_g` 之和等于全空间 `Z`（误差 <1e-9）。
  - A3：解析锚点 `Kp=0 ⇒ w_g=1/8, q_top=0`，在 L=2、L=3 上由精确/半精确手段复现到 <1e-9。
  - A4：给定任意 `w_g[8]`，`q_top=(8Σw_g²−1)/7` 与逆推往返一致。
- **交付物**：`033_stageA_*/` 下的验证脚本 + `summary.md`（贴出四项对比数字）。

### Stage B — 金标准参照表（「照妖镜」benchmark）

- **目的**：造一把能让错误估计量当场露馅的尺子。
- **做什么**：在 L=2 全枚举上，对一组**刻意选取**的 `(p,q)`，精确算出 `w_g[8]`、`ΔF_g[8]`、`q_top`。**`(p,q)` 要选到让 L=2 的真值 `q_top` 横跨约 `[0.2, 0.9]`**（高 q 或高 p 即可，不必是生产 `p=0.05`）。
- **成功闸门**：
  - B1：参照表里 **≥3 个点的精确 `q_top` 落在 `[0.2, 0.8]`**（能失败的点）。
  - B2：L=2 精确结果可独立复现（换随机种子/换实现，`w_g` 的 TV <1e-9）。
- **交付物**：`034_stageB_*/` 下 `exact_reference.json/csv`（含 `w_g[8]`、`ΔF_g`、`q_top` 与所用 `(p,q)`），`summary.md`。

### Stage C — 主线工具：sector-constrained 采样器

- **目的**：实现/复用一个「只在固定逻辑扇区 `g` 内采样」的 Markov chain，作为 TI 的引擎。
- **做什么**：所有 proposal `δ` 满足 `P_L δ=0`（局域 + stabilizer + syndrome move 保扇区）；非对称 proposal 用 Metropolis-Hastings。项目里可能已有部分实现（如 `src/exp37_sector_ti.py` 的 fixed-sector chain 路径），**优先复用并按本闸门验证，不要另起炉灶**。
- **成功闸门**：
  - C1：长跑后 `sector_trace` 恒等于指定 `g`；任何破坏扇区不变量的 move 直接 assert 报错。
  - C2：L=2 上，扇区内 `⟨|x|⟩`、`⟨|H_Z x ⊕ m_err|⟩` 的 MCMC 均值复现「L=2 精确扇区内均值」（相对误差落在 block-bootstrap 误差棒内）。
- **交付物**：`035_stageC_*/` 下采样器自检脚本 + `summary.md`（贴 C1 日志、C2 对照表）。

### Stage D — 主线估计量：sector-resolved TI

- **目的**：用 Stage C 引擎，沿 `K_p` 积分得 `ΔF_g → w_g → q_top`，作为生产主估计量。
- **做什么**：固定 `K_q`，`K_p` 从 0 到目标值建网格（在 `K_p` 上、不是在 `p` 上均匀），积分 `ΔF_g=∫₀^{Kp*}(⟨|x|⟩_g − ⟨|x|⟩_0)dK_p`；粗/细两套网格 + block bootstrap 误差。
- **成功闸门**（在 Stage B 金标准上，**必须包含那几个中段 `q_top` 点**）：
  - D1：`TV(w_TI, w_exact) ≤ 0.02`。
  - D2：`|q_top_TI − q_top_exact| ≤ 0.02`，且 bootstrap CI 覆盖精确值。
  - D3：粗/细 `K_p` 网格自洽：`TV(w_coarse, w_fine) ≤ 0.02` 且 `|Δq_top| ≤ 0.02`。
- **交付物**：`036_stageD_*/` 下 TI 估计器结果 + `summary.md`（逐点贴 TV、δq_top、grid 一致性）。

### Stage E — 第二条独立路径交叉验证（退火 + 双向）

- **目的**：用与 TI 机制不同的自由能估计量，证明 D 的结果不是某条路径的假象。
- **做什么**：实现「沿『打开逻辑 loop』方向退火」的自由能估计（如对 `ℓ_g` 加 λ∈[0,1] 逐步打开 + BAR / 双向 AIS）。**严禁退化为单步 FEP。**
- **成功闸门**：
  - E1：在 Stage B 金标准上，第二法 `TV(w, w_exact) ≤ 0.03`、`|Δq_top| ≤ 0.02`。
  - E2：第二法与 TI 三方一致：`TV(w_2nd, w_TI) ≤ 0.03`、`|q_top_2nd − q_top_TI| ≤ 0.02`。
  - E3：双向一致性诊断（前向/反向自由能差）在阈值内，能暴露而非掩盖偏差。
- **交付物**：`037_stageE_*/` 下第二法结果 + `summary.md`（贴三方对照：exact / TI / 2nd）。

### Stage F — 尺度放大 + 失败地图（L=3,4,5 × 生产网格）

- **目的**：把通过验证的主线放到生产 `(p=0.05, q=0.08…0.23, L=3,4,5)`，并对每个点给可信状态。
- **做什么**：用 TI 主线跑全网格；逐点输出 `w_g[8]`、`ΔF_g`、`q_top`、误差棒、`PASS/WARN/FAIL` flag；在抽样子集上用 Stage E 第二法做点对点核对。
- **成功闸门**：
  - F1：每个点都有明确状态；**任何「次主导扇区全部低于统计分辨率」的点标 `UNRESOLVED/FAIL`，不得报 `q_top≈1`**（铁律 3）。
  - F2：每个 PASS 点 粗/细网格自洽（同 D3 阈值）。
  - F3：抽样子集上 TI 与第二法 `|Δq_top| ≤ 0.02`；不一致的点降级为 WARN/FAIL。
- **交付物**：`038_stageF_*/` 下全网格结果 + 失败地图 `failure_map.md`（标 PASS/WARN/FAIL 与原因）。

### Stage G — 生产曲线

- **目的**：产出最终曲线并给可信度结论。
- **做什么**：只用 PASS 点，做 disorder bootstrap 误差棒，画 `q̄_top(L, q)`；明确标注 crossing/趋势是否由 PASS 点支撑。
- **成功闸门**：
  - G1：小 L 曲线与精确 benchmark 一致。
  - G2：曲线趋势/crossing **不依赖** FAIL/WARN 点；图中 WARN/FAIL 点可区分显示。
  - G3：曲线可从保存的 `w_g[8]` 完整重建；误差棒含 disorder + 自由能估计两层。
- **交付物**：`039_stageG_*/` 下最终 `npz/csv/md/png` + `acceptance.md`（逐条对照 G1–G3 与铁律 3）。

## 6. Definition of Done

A–G 全部 `PASS`，且：① 生产曲线只由 PASS 点构成；② 小 L 与精确解一致；③ 曲线可从 `w_g[8]` 重建；④ 没有任何「`q_top≈1` 但次主导扇区未分辨」的点被当成功；⑤ 关键趋势不依赖 FAIL/WARN 点。
