# Catalog-free MLB8-J16 V0 local transport preflight

This is a deliberately narrow, local development preflight for the
catalog-free multi-logical block kernel.  It is not a posterior estimate, an
independent confirmation, a remote discovery result, or permission to run the
formal exp102 scan.

## Frozen question

Can the new exact block itself visibly transport all 64 logical directions on
the difficult fixed hard coset

```text
m08_c06, p=.04, d00, attempt022
MLB8-J16, no logical proposal catalog
burn=512, measurement=4096
P/U/L, eight independent trajectories per family
```

`P` is the legal planted state.  `U` is an exact K=0 uniform hard-coset draw.
`L` is `P` XOR the deterministic XOR of all reduced logical directions.  It is
legal, has a nonzero logical signature, and depends on the code only; physical
all-zero is not substituted for any of these because the syndrome is nonzero.

Every macrostep has only a stabilizer heatbath sweep and one exact MLB block
heatbath.  The frozen empty catalog is rebuilt and checked in every trajectory;
therefore a changed logical label can only come from the multi-logical block.

## Gate and interpretation

For each initialization family, measurement-only labels must show at least 128
nonzero consecutive deltas, six of eight chains with at least eight deltas,
rank 64 over those deltas, and a leave-return for every basis and frozen
nonbasis character.  On this m8 catalog-free kernel a rank-64 label-delta set
already requires transport through all eight disjoint logical block windows.
Failure is useful negative evidence and is not repaired by changing starts,
extending a chain, or lowering a threshold.

Passing only grants `LOCAL_LOGICAL_TRANSPORT_VIABLE_FOR_HARD2_SCREEN`.  A
fresh three-node contract must still add source/archive binding, cross-host
reference/Numba preflight, immutable raw/replay audit, P/U/L convergence
checks, T/2T, an independent mechanism, and panel/held-out gates before any
formal run can be considered.
