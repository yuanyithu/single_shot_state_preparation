# Collapsed-B Houdayer structural feasibility

This frozen local probe asks whether a generalized Houdayer swap has useful
component geometry in the exact collapsed-HGP B marginal, before a new
HP64-plus-HCA pair kernel is implemented.

For `H A xor B H = Y`, the collapsed cold target is

```text
pi_B(B) proportional to (p/(1-p))^|B| product_j M_p(Y[:,j] xor B H[:,j]).
```

The B variables whose two replicas differ are connected when they occur in a
common collapsed column factor.  Swapping one complete connected component
exchanges the two inputs of every touched factor and the unary B bits, hence
preserves the product target exactly.  The probe checks this invariant for all
evaluated component subsets; it does not sample a Markov chain.

The P-derived low-energy catalog, L/L schedule, one exact-K=0 U/U pair, factor
representation, component-subset cap, and terminal decision are frozen in the
canonical config.  A new unordered B pair is the only structural signal.  A
new full physical pair or an A-column redraw would not count because the
collapsed B state is the intended slow variable.

A positive structural result would authorize only an independently exact,
fresh local pair-kernel test with P/U/L starts.  It does not establish mixing,
tail control, a posterior, `q_top`, remote work, formal readiness, held-out
work, or production.
