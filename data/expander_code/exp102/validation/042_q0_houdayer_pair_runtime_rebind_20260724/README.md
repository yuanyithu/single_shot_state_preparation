# HCA-RHB1 runtime source rebind

`040` measured the same frozen runtime configuration before the shared pair
module received initialization-catalog infrastructure.  The transition kernel
did not change, but a fail-closed local viability run must bind its runtime
evidence to the exact current source hash.  This directory is therefore a
fresh, outcome-blind replay of the unchanged 040 schedule and timing pair.

It reads no posterior statistic and is not an additional sampler screen.  Its
only purpose is to produce a new immutable runtime report whose pair-kernel
source hash matches the source frozen by the subsequent local viability run.
