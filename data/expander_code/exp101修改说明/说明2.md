# exp101 physics contract

本文适用于 data/expander_code/exp101/ 下的所有代码、测试、扫描和文档。
exp101 不使用根目录 AGENTS.md 中 legacy 3D delta-only 模型作为论文物理定义。
本目录的物理权威是 PHYSICS_CONTRACT.md。

## 1. 研究对象

论文协议是：

    |+>^n
      -> 一次带 readout error 的全部 Z-check 测量
      -> preparation-induced X-error channel S
      -> 独立 stochastic X data noise N
      -> 一次完美 final Z-syndrome measurement
      -> MAP/MLD on logical classes.

因此生产 sector 是：

    sector = x_error
    H_check = H_Z
    stabilizer moves = rows(H_X)
    logical moves = logical_X
    logical observables = logical_Z
    prepared stabilizer state = |+>_L

不要把 x_error/H_Z 写成 |0> preparation。
其 Hadamard 对偶才是：

    z_error / H_X / Z errors / |0>_L preparation.

当前 assemble_sector_model 的 H_X/H_Z 接线已经正确；
只修正文档中的状态名称，不要交换代码矩阵。

## 2. 原始物理变量

使用互不重名的变量：

    sigma_prep      : 制备投影产生的真实 physical syndrome, in im(H_Z)
    delta_meas      : 制备 readout error
    s_prep          : sigma_prep XOR delta_meas
    epsilon_data    : 制备后独立叠加的真实 X data error
    c_prep(sigma)   : H_Z c_prep(sigma) = sigma
    F_total         : c_prep(sigma_prep) XOR epsilon_data
    sigma_final     : H_Z F_total
    y_eff           : s_prep XOR sigma_final
                    = H_Z epsilon_data XOR delta_meas

exp101 模拟的是消去 sigma_prep 后的 reduced MLD problem，
不是逐步 Clifford/circuit simulation。

代码变量重命名约定：

    disorder.eta                -> epsilon_data_true
    disorder.delta              -> delta_meas
    disorder.observed_syndrome  -> y_eff / effective_syndrome

可暂时保留旧字段作为兼容 alias，但新文档和 manifest 禁止继续混用名称。

## 3. 唯一的论文生产 posterior

MCMC canonical state e 表示候选 absolute data error。

    pi(e | y_eff)
      proportional to
    exp[-K_p |e| - K_q |H_Z e XOR y_eff|].

因此：

    sigma_arg = y_eff.

真实 epsilon_data_true 不得直接进入 Gibbs energy、Metropolis
acceptance ratio、proposal probability 或 sector free energy。

它只允许用于：

1. 生成 y_eff = H_Z epsilon_data_true XOR delta_meas；
2. 计算 relative/Mattis reference label；
3. 模拟后的 scoring、Nishimori identities 和 ground-truth tests。

## 4. 坐标变换与 legacy 模型

论文 posterior 的严格 shifted coordinate 是：

    x = e XOR epsilon_data_true
    
    E_shifted(x)
      = K_p |x XOR epsilon_data_true|
        + K_q |H_Z x XOR delta_meas|.

这与 true_posterior 逐构型等价。

旧仓库模型是：

    E_legacy(c)
      = K_p |c XOR epsilon_data_true|
        + K_q |H_Z c XOR y_eff|,

它换元后成为：

    K_p |u| + K_q |H_Z u XOR delta_meas|,

即 delta-only ensemble。

因此：

    true_posterior     = 论文生产模型
    legacy_delta_only  = 旧程序回归模式

保留 repo_compat 仅作为 legacy_delta_only 的 deprecated alias。
禁止用 legacy_delta_only 生成论文相图或阈值结论。
不要再向用户提出这两个模式的二选一。

## 5. 三种不同的 section/decoder 不得混名

    r_meta:
        C^2 -> C^2
        syndrome-readout / metacheck decoder
    
    c_prep:
        im(H_Z) -> C^1
        preparation syndrome 的 data-chain representative
    
    r_sec:
        im(H_Z) -> C^1
        logical-sector labeling 使用的 section

代码中的 model.section 是 r_sec，不是 r_meta。
q>0 时 y_eff 通常不在 im(H_Z)，绝不调用 section.apply(y_eff)。

## 6. 逻辑类与 observable

定义：

    phi_r(e) = logical class of e XOR r_sec(H_Z e).

absolute posterior character:

    m_u_abs = E[(-1)^(u dot phi_r(e)) | y_eff].

模拟可使用相对真值的 Mattis-centered character：

    m_u_rel
      = (-1)^(u dot phi_r(epsilon_data_true)) m_u_abs.

二者只差符号，因此 q_top 相同。

论文 order parameter 必须定义为：

    q_top = mean over every nonzero u of m_u^2.

full-character 模式精确计算。
sampled-character 模式必须对全部非零 u 的平均保持无偏，
不能只平均 non-basis 样本而漏掉 basis characters。

有限 MCMC 下 m_hat^2 有正偏，使用独立 blocks/chains 的
cross product 或 U-statistic 去偏。

## 7. decoder success 的语义

    w_truth = posterior mass assigned to the actual logical class.
    
    P_succ = max_l P(l | y_eff).

两者不是同一个量。

full weights 可用时输出：

    p_succ = max(weights_absolute).

只有 sampled characters 时输出由 q_top 得到的上下界，
不要把 w_truth 命名为 success probability。

## 8. 生产算法限制

    k <= 10:
        full-TI 可以用于 q_top。
    
    k > 10:
        pairwise-TI 禁止用于 q_top；
        只能输出 per-u gap diagnostics。
    
    k > 10 and q > 0:
        使用 PT observable sampling，并要求 sector-transport gate 通过。
    
    q = 0:
        使用已经验证的 q=0 路径，并要求多起点/sector gate 通过。

任何 gate 失败的结果不得进入 mean_q_top 或 crossing analysis。

## 9. 必须存在的 golden tests

1. paper physical variables 与 reduced posterior 的逐构型等价测试；
2. true posterior energy 不直接读取 ground-truth error 的测试；
3. shifted-coordinate pointwise identity；
4. legacy_delta_only 与 true_posterior 在非平凡 disorder 下确实不同；
5. x_error/H_Z 对应 |+> preparation 的 convention test；
6. sampled q_top 对人工给定全部 character 数据的无偏测试；
7. w_truth != P_succ 的反例测试；
8. k>10 请求 pairwise q_top 必须硬报错；
9. manifest 必须记录 physics contract version、ensemble、
   syndrome semantics 和 section fingerprint。
