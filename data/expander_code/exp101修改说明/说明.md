    二、物理制备 convention
    
    论文主问题是：
    
        |+>^n
          -- measure noisy Z checks -->
        logical |+> preparation
          -- X-type residual/preparation error -->
          -- additional stochastic X noise -->
        final perfect syndrome + MLD.
    
    因此：
    
        x_error / H_Z checks  <-> logical |+> preparation
        z_error / H_X checks  <-> logical |0> preparation
    
    不要交换 assemble_sector_model 中的 H_X/H_Z 接线。
    当前 x_error 接线：
    
        H_check = H_Z
        stabilizer_rows = H_X
        logical observable basis = logical_Z
        logical move basis = logical_X
    
    在代数上是正确的；只修正文档和注释中的 |0>/<+> 标签。
    
    三、严格区分物理层和 Nishimori canonical 层
    
    物理层观测包括 preparation record s_prep 和 final syndrome sigma_F。
    统计力学配分函数依赖其组合 syndrome argument。
    
    论文 Nishimori 表示中，重命名：
    
        d_q   ~ Bern(q)       # 论文公式中原来写作 s 的 q-disorder
        eta_p ~ Bern(p)
        c_raw                 # 论文原始统计变量
    
    论文权重：
    
        W_paper(c_raw; d_q, eta_p)
          = p(c_raw xor eta_p)
            q(H_check c_raw xor d_q).
    
    定义 canonical 变量：
    
        v = c_raw xor eta_p
        y = d_q xor H_check eta_p.
    
    则逐构型严格有：
    
        W_paper(c_raw; d_q, eta_p)
          = p(v) q(H_check v xor y).
    
    代码中的 canonical sampler 必须使用：
    
        eta_planted ~ Bern(p)
        measurement_disorder ~ Bern(q)
        combined_syndrome_argument
            = H_check eta_planted xor measurement_disorder
    
        pi(v | combined_syndrome_argument)
          proportional to
          exp[-K_p |v|
              -K_q |H_check v xor combined_syndrome_argument|].
    
    这就是论文模型，也是当前 true_posterior 应有的唯一生产语义。

    六、logical observable
    
    定义：
    
        phi_r(v)
          = logical class of
            v xor r_chain(H_check v).
    
    paper absolute observable:
    
        O_u_abs(v) = (-1)^(u dot phi_r(v)).
    
    可选 planted-relative observable:
    
        O_u_rel(v; eta_planted)
          = (-1)^(u dot phi_r(eta_planted))
            O_u_abs(v).
    
    因此：
    
        m_u_rel
          = (-1)^(u dot phi_r(eta_planted)) m_u_abs,
    
        q_top_rel = q_top_abs.
    
    相对 frame 只允许用于 planted-overlap/Nishimori 估计；
    输出和文档必须说明 absolute 与 relative 的区别。
    
    q_top 对 Mattis sign 和全局 sector translation 不变，
    但不要声称它对任意改变 r_chain 都不变。
    syndrome-dependent logical section change是不同 correction protocol；
    每个 run 必须记录 section fingerprint。
    
    七、严格区分三个量
    
    对于 absolute logical-sector posterior P_l：
    
        posterior_purity = sum_l P_l^2
    
        q_top =
          (2^k posterior_purity - 1)/(2^k - 1)
    
        posterior_mass_on_planted_class
          = P_{phi_r(eta_planted)}
    
        map_success_probability
          = max_l P_l
    
    不得把 posterior_mass_on_planted_class 或 purity
    命名为 MLD success probability。
    
    在 full-sector 路径中同时输出：
    
        weights_absolute
        weights_relative
        posterior_purity
        posterior_mass_on_planted_class
        map_success_probability
        q_top
        q_top_lower_bound_on_Psucc
        q_top_upper_bound_on_Psucc.
    
    八、数值方法硬约束
    
    1. full sector-TI 只允许 k <= 10。
    2. k > 10 时，pairwise-TI 禁止作为 q_top estimator。
       请求 q_top + engine=ti 时必须硬报错，不能只返回 flags="PAIRWISE"。
    3. 大 k 使用 direct/PT sampled-observable 路径。

       增加 engine=pt 或 engine=direct_pt。
    5. 无 PT round-trip 且 worst-u logical transport 不足时，

    6. CLI 默认不能再是对大 k 自动落入 pairwise 的 ti。
    
    九、q_top 估计器
    
    MCMC 不得直接把有限样本 m_hat 平方当作无偏 m^2。
    实现 block/independent-chain cross-product debias：
    
        m2_hat_u = m_hat_u_block_A * m_hat_u_block_B
    
    并同时输出 raw 与 debiased 版本及误差。
    
    大 k sampled-u 从 nonbasis characters 抽样时，使用：
    
        N = 2^k - 1
    
        q_top_hat =
          [sum_basis m2_hat_u
           + (N-k) mean_sampled_nonbasis(m2_hat_u)] / N.
    
    一阶 m 的全 character 平均使用同样的 basis/nonbasis 加权，
    不得直接用 nonbasis mean 代替全部非零 u mean。
