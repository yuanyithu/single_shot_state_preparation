- 2026-08-08：**exp104 完成并发布，终态 `EXP104_CERTIFIED_CROSSING`，`p_cross = 0.05512`（95% bootstrap CI `[0.05327, 0.05699]`）**。解码器与 exp103 逐字段相同（BP+OSD-0），只把预算从「每码 10000 trial」改成「每个 m 随机抽 2000 个码、每码每 p 只跑 4 次」，不做任何后选择。nd-3 单节点 64 workers，778 个 task 全部 fresh，扫描 **45.9 分钟**，承诺的 10% 抽样复现 83/83、60,120 个 trial 逐位一致，108,000/108,000 个 code-p 单元 `REPORTABLE`，共 **432,000 个 trial（比 exp103 少 14.4 倍）**，经 loader 在本机独立复核。主对比 `Δ38` 在 p=0.03/0.04/0.05 认证为负、p≥0.06 认证为正，认证 bracket **`[0.05, 0.06]`**；同时置信带半宽 **`0.0211`**（exp103 是 0.2601，**窄 12.3 倍**），最大 cluster SE `0.00652`（exp103 是 0.115）。p=0.02 **未认证**（`Δ38=-0.0096` 落在带内），据实标注。**exp103 的反常已被测量解释**：该族 classical-distance-2 码的占比随尺寸单调下降（`0.229 → 0.104`，20,000 样本/每 m、两个独立 seed 复核到 0.0006），而 exp103 的 8 码面板实际抽到 `0,3,2,2,0,1` 个——m=3 一个都没抽到（应有约 23%），使 `P_fail(m3)` 偏低、把 `Δ38` 整体推成正的。exp103 的解码器/种子/打分并无问题：Validation 002 在同一台机器上用两个包跑 60,000 个 trial，逐个 per-trial 数组完全一致。**顺带测出**：该编译解码器不具跨平台逐位可移植性（macmini 与 nd-3 失败数差 <1%，BP 收敛率不变，差异在 OSD 后处理），故 exp104 全程只在 nd-3 生成/复现/聚合，不跨平台混用 artifact。不主张任何渐近阈值、指数、FSS、`q_top`、MLD 或 preparation 结论；exp102 仍为 **`BLOCKED_BEFORE_REMOTE`**，本实验未解除其任何 blocker。证据见 [Validation 005](../data/expander_code/exp104/validation/005_final_crossing_20260808/) 与 [exp104 status](../data/expander_code/exp104/status.md)。
